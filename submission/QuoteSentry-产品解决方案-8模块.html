02 / PAIN

痛点场景

93 字 / 80–100 字

高混紧固件外贸商每天从邮件、Excel 和 PDF 中拆出多行询价，再补标准、材质、强度、表面处理和数量。缺参、写法冲突或目录外规格一旦被相似 SKU 替代，就会造成错报价、返工、空运和审批无痕。

03 / SOLUTION

解决方案

113 字 / 80–120 字

QuoteSentry 用 Agent 逐行读取询价并回指原文，先做缺参、冲突和单位门禁，再回私有目录硬匹配 SKU，由确定性规则计算折扣、阶梯价、汇率、费用和毛利。异常行被明确阻断，模型只做抽取和解释；审批、导出和外发必须由人确认。

边界：大模型不计算价格，不决定 SKU，不自动审批、不自动导出、不自动外发。

05 / USER FLOW

使用流程

99 字 / 80–100 字

进入对话审单，发送询价或上传表格；Agent 逐行抽取并标记可报价、待澄清和目录外。补充缺失字段后自动重算，进入报价审批核对客户视图、成本和毛利。人工确认后导出客户 CSV/PDF，审计时间线记录过程。

06 / DIFFERENCE

差异化价值

79 字 / 60–80 字

通用大模型能读会写，却不掌握客户目录、协议价和审批责任；人工报价依赖经验、难以追溯。模型只做抽取与解释，价格交给规则，承诺动作交给人，可阻断、可复核、可追责。
